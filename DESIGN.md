# Direção visual do PostAI

Referência: HTML navegável fornecido pelo usuário, lido sem alterações. Interface de trabalho em português para a equipe Piersec.

- HeroUI v3 para todos os componentes de interface. Tailwind para disposição e espaçamento; tokens semânticos para personalizar a biblioteca.
- Navegação lateral navy `#10151F`; fundo `#F2F3F6`; texto `#10151F`; texto secundário `#586275`; borda `#DCE0E8`; ação principal `#2D4BFF`.
- Bricolage Grotesque para títulos, Source Sans 3 para texto. Arquivos locais extraídos dos recursos da referência.
- Cartões discretos, sem sombras decorativas. Informação útil antes de ornamentação.
- Navegação passa a ocupar o topo em telas estreitas. Formulários refluem; tabelas têm rolagem horizontal.
- Estados reais: vazio, carregamento, erro, sucesso, permissão restrita e integração ainda não configurada.
- Identidade das publicações Piersec: navy e ciano, fotografia editorial profissional, tom consultivo e analítico. Regras de imagens e texto vêm dos documentos, tratados como dados de referência.
